Requirement row for the gap analysis: term, required/nice-to-have, plain-language state, one action.
```jsx
<KeywordRow term="REST APIs" required state="omitted" detail="Payroll API project at BridgeWorks — in your Base CV." action={<Button size="sm">Add</Button>} />
<KeywordRow term="SQL" state="included" detail="Mentioned in 2 roles." />
```
"gap" is neutral grey, not red: a gap is information, not failure.
