Action button with a tactile press; exactly one `primary` per screen or step.
```jsx
<Button variant="primary" size="lg" iconRight="arrow-right">Check my match</Button>
<Button icon="upload">Upload CV</Button>
<Button variant="ghost" size="sm">Skip for now</Button>
```
Labels are verb-first and say what happens ("Add to this CV", not "OK"). `loading` keeps width and shows a spinner.
