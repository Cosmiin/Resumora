Status tag for confirmation state, keyword state, application stage.
```jsx
<Pill tone="good" icon="check">In your CV</Pill>
<Pill tone="warn" icon="circle-help">Needs checking</Pill>
<Pill tone="info">You have this — not in this CV</Pill>
```
Tones: good = confirmed/included, warn = needs your confirmation, bad = confirmed gap, info = available elsewhere, neutral = draft/untested.
