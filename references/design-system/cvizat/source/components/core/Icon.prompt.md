Lucide icon that inherits text colour; use for every glyph in CVizat UI (never emoji).
```jsx
<Icon name="sparkles" size={18} />
<Icon name="circle-alert" color="var(--status-warn-fg)" label="Needs checking" />
```
Sizes: 16 inside pills/small buttons, 18 in buttons and nav, 20–24 for empty states. Names: https://lucide.dev/icons
