Brand logo (open door, sunrise light) — use instead of typing the name wherever the brand appears.
```jsx
<Logo size={30} />                      // nav, headers
<Logo variant="mark" size={28} />       // tight spaces, flow top bar
<Logo tone="inverse" size={40} />       // on pine-600 / pine-800
```
Minimum: mark 16px (rays drop automatically below 24px), lockup 20px tall. Clear space = door width on every side. Never recolour the light, remove the gradient on colour versions, stretch, or add effects. Static files: `assets/logo/`, favicons `assets/favicon/`.
