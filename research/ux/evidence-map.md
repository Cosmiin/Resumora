## Navigation evidence

- **Observed controls, unverified transitions:** S07–S12 and S16–S29 show Continue; many show back; S14 shows upload/manual alternatives; S33 shows URL add/skip; S39 shows Edit/Accept; S44 shows CV selection/create/Continue.
- **Probable sequence (inference):** S07 → S08 → S09 → S10 → S11 → S12 → S13 → S14 → S15 → S16…S32 → S34, supported by numeric filenames, increasing mtime and progress. Missing onboarding17 is not silently invented. S33 interrupts the timestamp series and may be a separate job flow.
- **Editor cluster (observed coexistence, inferred route):** S35/S38 chat + preview ↔ S36 styling; S37 translation modal; S39 experience proposal; S42 structured edit. Captures do not establish which editor is default.
- **Job branch (inference):** S33 URL import → S43 document hub → S44 Base selection → adaptation/editor. S43 precedes S44 by mtime, but no navigation event is captured.
- **Billing branch (inference):** S40 offer → S41 checkout, supported by term/plan consistency and adjacent mtime. Payment completion absent.
- **Public navigation:** S01–S06 share a public-site navigation/footer and cross-feature links; marketing illustrations must not be mistaken for verified app states.
