# Strategy assumptions — v1, 2026-10-23

The approved baseline is authoritative. Recommendations below are not approval.

| ID | Assumption / uncertainty | Consequence / validation |
|---|---|---|
| A-01 | Romanian job seekers using both RO and EN are the initial segment. | Baseline language direction; narrower occupation/experience segment unresolved. Test examples with juniors, career changers and experienced applicants. |
| A-02 | Truthful career-fact enrichment and explainable gaps create more value than additional generation tools. | Hypothesis; no interview or conversion evidence yet. Compare tasks with a template-only baseline. |
| A-03 | A small bilingual alias dictionary handles enough initial jobs. | Hypothesis; audit false positives for tools, negation, ambiguous terms, regulated qualifications. |
| A-04 | A tested single-column PDF is an acceptable initial export. | Recommendation; employer file requirements vary. DOCX import versus export are separate choices. |
| A-05 | Public competitor pages describe available features accurately. | Only advertised functionality verified; no account-based functional tests, employer ATS integration tests or audited outcome data. |
| A-06 | Public displayed prices are comparable only after billing/currency/offer/tax caveats. | No checkout/purchase performed. Unknown final tax/locale amounts must stay unknown. |
| A-07 | Approval of discovery does not approve proposed MVP reductions. | Retain all baseline journeys in discovery, escalate release exclusions to Firstmate. |

Primary uncertainties: closed score formulas, exact multilingual behavior, provenance/confirmation implementation inside competitors, employer ATS settings, willingness to pay, actual parsing accuracy and unmeasured inference workload.

A-08 (strategy round 1): a lean application/contact/next-action record and supplied-text LinkedIn review may satisfy the requested aim without a full CRM/account integration. This is a simplification hypothesis, not approved launch scope. Previous narrow candidate explicitly deferred; D-13/14 require review. Every canonical section gets readiness advice/questions, with progressive/skip behavior still a UX choice rather than deletion of coverage.
