## What earns a convincing proposal

One UX-owned guided entry, one Mara/job/fact/version story, primary action and visible next step on each screen, immediate Base value, realistic full-size editor/document, meaningful edits/undo/recovery, then an application record the user can return to. Ask decisions only when their effect has been shown. Keep method/cost detail in linked support views. Owner feedback on understanding/fidelity is acceptance evidence to address; passing code/layout checks alone does not settle it.

No automatic applications/messages, broad scraping, purchased contact enrichment, real checkout or model experiments. No employer-score equivalence, “ATS passed” from a preview, hiring probability or invented facts. Before any implementation, Firstmate consolidates requirements/UX/architecture/MVP/budget decisions and explicit approval.

Terminal strategy feedback requires latest CV with honest tailored status, search and sent count in the lean workspace; all options retain them. Sent snapshot history remains independently available. Search/sent metrics are not deferred as “advanced CRM.” See terminal-strategy-feedback.md.
