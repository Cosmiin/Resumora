## Configuration requirements and remaining runtime ownership

Both buckets remain private and require existing authenticated tenant access, operation-aware Storage policies, restricted immutable object paths and live reservations. Import completion uses the existing `AI_WORKER_SECRET` and its restricted authorization hash; model activation is a separate policy, and reopening never invokes a provider. Photos require dedicated `PHOTO_WORKER_SECRET` (32–128 base64url characters) and the matching existing `app.photo_worker_config` SHA-256 singleton, in addition to user auth/RLS.
